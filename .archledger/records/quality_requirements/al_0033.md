## Scenario

Given toktrail installed with default configuration, when any command is executed,
then zero network connections are made to any external host.

## Quality attribute

Privacy / Security

## Measurement

- No `urllib`, `requests`, `httpx`, or socket connections in runtime code.
- No telemetry endpoints or analytics SDKs.
- Pricing comes from local TOML files only.
- Raw source JSON stored locally only when `--raw` is enabled.

- `pyproject.toml` — dependencies (no network libraries)
